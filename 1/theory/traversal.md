# Обходы

* *Обход в глубину* - контейнер стек. O (|V| + |E|)
* *Обход в ширину* - контейнер очередь. O (|V| + |E|)

## Ордеры

* PreOrder - действие до обхода всех преемников
* PostOrder - действие после обхода всех преемников

## Классификация ребер и вершин

Вершины:

* Новая - если обход еще не зашел count < Vpre
* Активная - если обход зашел но еще не обаботал преемников Vpre < count < Vpost
* Обработанная - если обход закончил с вершиной, Vpost < count

Ребра. Ребра по счетчикав в инц. ребрах. Ребро e : (u, v) называется:

* Ребром дерева, если впервые открыта вершина v и она является прямым потомком u. Upre < Vpre < Vpost < Upost.
* Обратным ребром, если соединяется вершина предок u с потомком v, к-ый уже находится в дереве поиска, v - уже активная. Vpre < Upre < Upost < Vpost. Ребро замык. цикл.
* Перекрестные ребра - все остальные ребра графа. V уже обработана, Vpost < Upre.


# DAG

Directed Acyclic Graph - ориентированный орграф.

Можно выделить *начальный* вершины без входных ребер и *конечные* вершины без выходных ребер.


# Топологическая сортировка

Отношение упоряд. u < v для каждого u -> v и Upost > Vpost. Невозможно для циклов, тк Upost < Vpost.
