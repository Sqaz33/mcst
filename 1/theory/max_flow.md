# Транспортная сеть

*Транспортная сеть* G = (V, E) орграф, где каждое ребро e : u -> v, имее пропускную способность c(u, v) >= 0. В данном графе запрещены петли. Выделяют S исток, T сток. Для каждой вершины v существует путь из S в T через v.

Поток в данной сети это функция f: V x V -> Вещ. числа, к-рая удовл. двум условиям:

1. Поток по любому ребру не может быть отриц., и превосходить пропуск. способ. этого ребра.
2. Для любой вершины, кроме S стока и истока, общий вход. поток равен общ. исход. потоку.

Величина потока равна сум. потоку, выход из истока S, минус сум. поток, входящий обратно в исток S.

# Метод Форда - Фалкерсона

Остаточная сеть - это граф Gf(V, Ef) с емкостью Cf(u, v) = c(u, v) - f(u, v)

Метод:

1. Оста. сеть. сначала совп. с исходной сетью.
2. В остат. сети находим любой путь из источника в сток. Если пути нет - закончили. (поиск в ширину)
3. Через этот путь пропускаем макс поток:
   a. на пути ищем ребро с Cmin
   b. в каждом ребре увеличиваем поток на cmin, а в противоположном уменьшаем. 
   c. для всех ребер пересчит пропуск способ.
